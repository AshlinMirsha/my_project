# 🎨 AirCanvas

AirCanvas is a real-time virtual drawing application built using Python,
OpenCV and MediaPipe.

## Features

- Hand tracking
- Finger-based drawing
- Multiple colors
- Eraser
- Clear canvas
- Undo
- Save drawing
- Gesture recognition

## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
